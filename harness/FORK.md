# IDEalize V1 — fork notes

This repository is a hard fork of [deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness) (MIT).

- **Fork point**: upstream commit `99f6f02fecdb7dff40c3fbc9470f5907c29f74ca` (v0.1.0-rc.7), forked 2026-08-18.
- **Remotes**: `origin` = jamiejefferson/IDEalize (the private working repository); the public jamiejefferson/IDEalize carries the harness under `harness/` from V1's go-live (JJ, 16 Sep 2026: one repository, older versions archived within it); `upstream` = deepseek-ai/deepseek-harness.
- **Repo name**: `idealize-v1` because GitHub resolves repository names case-insensitively and `jamiejefferson/IDEalize` is the V0 app (the previous IDEalize, kept as branch `v0` and tag `v0-final` at V1's go-live; its design is what V1 re-implements, and "V0" in the rows below names that design).

## Discipline

- IDEalize code lives in `packages/idealize/*` plus the `idealize` profile template; upstream packages are modified only when a seam is missing, and every such change is listed below.
- Composition changes go through profile/patch rows, never upstream boot code.
- Upstream merges are deliberate and tested; the day upstream drifts too far, we stop merging and own the tree.
