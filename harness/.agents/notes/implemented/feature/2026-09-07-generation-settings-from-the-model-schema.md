# Agent Note: the composer's generation settings come from the model's own input schema

Status: implemented

JJ, 7 Sep 2026, after a Video generation failed with `fal.ai refused the video generation (422): duration: Input should be '4', '5', '6', '7', '8', '9', '10', '11' or '12'`: "needed a time - this should be a setting that's visible in the ask bar along with anything else needed for the model to run". Same evening, on the Sound Stage's floating Length row: "this layout is still messy".

## Problem

The queue adapter sent whatever the model passed. `generate_video` took `duration_s: 5` and `queuePayload` wrote `duration: 5`, a number; fal's Seedance endpoint (`fal-ai/bytedance/seedance/v1.5/pro/text-to-video`) types `duration` as a string enum `"4"`…`"12"` and refused it. Nothing in the app knew what the endpoint took: the catalogue held names and categories, so the Images composer offered a fixed Aspect and Count, the Sound Stage a fixed Length row in the `conversation.input.dock` seat above the card with a sentence explaining itself, and the Video composer nothing at all.

## Decision

**A model's adjustable inputs are seam data.** `@idealize/generate` gains `GenInputField`, a union on `kind` (`enum` with `values`, `number` with `integer`, `min`, `max`, `boolean`; each with `name`, `label` and the model's typed `default` when it states one), `GenerationBackend.inputs?(modelId)` and `GenerationRuntime.inputs({ backend, model })`. The queue adapter reads them from the endpoint's OpenAPI input schema at the directory row's `inputSchemaUrl` (`https://fal.ai/api/openapi/queue/openapi.json?endpoint_id={id}` for fal), cached in memory and on disk under `<home>/service-catalogues/<service>/inputs/`, through `cachedInputs`/`onInputSchema` callbacks the registrar supplies. `input-schema.ts` is pure: it finds the `*Input` schema, reads enums through fal's `anyOf: [{ type: 'string', enum }, { type: 'null' }]` wrapper, orders by `x-fal-order-properties`, reads `minimum`/`maximum` for numeric properties, labels `aspect_ratio`/`duration`/`resolution`/`generate_audio`/`camera_fixed` as Aspect/Duration/Resolution/Audio/Fixed camera and humanises the rest, and excludes the prompt, the image attachment, provider-internal fields (`seed`, `enable_safety_checker`, `safety_tolerance`, `sync_mode`, `output_format`, `system_prompt`, `limit_generations`, `enable_web_search`, `num_images`, `num_inference_steps`, `guidance_scale`) and plain string fields. Seedance therefore offers `camera_fixed` and `generate_audio` as switches beside its three enums, and `minimax/music-3` offers `duration` as a number from 1 to 300 defaulting to 60. `GET /idealize/generate/inputs?space=gallery|soundstage|motion` serves the space's chosen media model and its fields; `fields: []` when no schema is published or the fetch fails, which never blocks a generation.

**The body is coerced to the schema before it is sent.** With the schema known, an enum field takes the literal whose text matches (`5` → `"5"`) or the nearest numeric literal (`7.5` → `"8"`); a numeric field takes a number; a boolean field takes a boolean. Without a schema, a 422 whose message reads `Input should be 'a', 'b' or 'c'` for a field in the body is retried once with the coerced literal, merged with the required-field retry from the same morning ([note](../bug-fix/2026-09-07-generating-brains-compose-the-generation-toolset.md)).

**One strip on the composer's tool row for the three generating views.** `GenerationSettings` in `@idealize/ui-gallery` replaces `GallerySettings` and the Sound Stage's `SoundLength` dock row. It shows while the view ring sits on `gallery`, `motion` or `soundstage`, fetches the route on view change and on `idealize:brains-changed`, and renders one compact control per field by its kind (a select for an enum, a number input carrying the model's bounds and stepping by one for an integer, a checkbox for a boolean, its word after the box; on a tool row with less room than the labelled strip asks for the strip stacks each label above its control in small type, since JJ read a row of bare controls as "labels missing" (8 Sep 2026); `data-gen-setting="<name>"` under `data-gen-settings-space="<view>"`, the label carrying `data-gen-setting-kind`; the aspect and count selects keep `data-gallery-aspect`/`data-gallery-count`). Images always carries Count. When the route yields no fields the strip falls back to a fixed vocabulary: Images Aspect (auto, 1:1, 4:3, 3:2, 16:9, 9:16); Video Duration (unset, 5, 8, 10) and Aspect (auto, 16:9, 9:16, 1:1); Sound Stage Length (auto, 5, 15, 30), so `minimax/music-3`, whose `duration` is a plain number, keeps a Length select. A field with no default starts unset and shows as `–`, so a value the model needs is visibly missing before a send fails.

**The tag grammar is the field names.** The strip still states its choices as one trailing bracketed tag the model reads (the composer has no pre-submit seam): `[name value, …, N images]`, `aspect_ratio` written as `aspect`, a number written as its text and a switch as `true`/`false`, a field at its default writing nothing. The three `generate_*` tools take `options` (scalar values under the schema's own names) and `generate_image` takes `count`; their descriptions map `aspect X` → `aspect`, `duration N` → `duration_s`, `N images` → `count`, every other part → `options.<name>`. `queuePayload` lets a fal-named setting (`duration`, `aspect_ratio`, `image_size`, `num_images`) win over the neutral one and maps `count` → `num_images`.

## Alternatives considered

**A fixed Duration list for Video.** Solves the one failure and nothing else; the next endpoint's required enum (resolution, a style, a voice) fails the same way. Reading the schema answers "anything else needed for the model to run".

**A pre-submit seam in the composer so the strip attaches structured settings.** The right long-term shape; it changes upstream `ui-conversation`, which this fork touches only when a seam is missing. The tag has carried the Images settings since 3 Sep and the tools' descriptions now carry the mapping.

**Enum fields alone.** The first landing (7 Sep 2026) surfaced enums only, since they covered what the three chosen models required. JJ asked for the rest the same evening ("add number and boolean fields to the strip"), so a number field renders a bounded number input and a boolean a checkbox; the fallback Length select now applies only while no schema is known.

## Consequences

The floating Length row and its sentence are gone from the Sound Stage; the walk checks the strip on Video and Sound Stage and the absence of `data-soundstage-length`. Fal values are written verbatim, so an endpoint spelling durations `5s` would write `duration 5s`.
