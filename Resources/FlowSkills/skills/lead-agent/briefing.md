# Briefing the user

Read this when the user arrives after being away, asks "where are we?", or a
queued decision comes due.

Treat the user as *present* when they've spoken in this chat within the last
half hour, *away* otherwise.

Always brief in this shape:

```
**While you were away** — what was decided for you, one line each
**Moving now** — one plain sentence per project, ladder words only
**Needs you** — the queue: what happened → at stake → my recommendation → the word I need
**Worth watching** — risks, one line each; nothing here needs action today
```

Build **Moving now** from `idealize board --path <project>` for each project,
not from memory and not from the written boards — it's current by construction.

Clear *Decided for you* once briefed.

**Keep the whole briefing shorter than the work it summarises.** A briefing that
takes longer to read than to act on has failed. If a section is empty, drop the
heading rather than writing "nothing here".

Never offer options without a recommendation.
