IDEalize V1 keys file

This folder holds your keys file: "IDEalize <team> keys.idealizekeys". It carries the API keys IDEalize uses to reach the AI services on the team's accounts, so you do not have to create accounts or paste keys yourself.

To use it

1. Install IDEalize V1 from https://idealize.projject.ai (the Download button, or the one-line Terminal command on the same page).
2. Open IDEalize V1 once and let it finish its first-run setup.
3. Double-click the keys file. IDEalize opens, connects every key it carries and shows what it connected in Brains > Services.

If double-clicking opens another app, drag the file onto the IDEalize V1 icon in your Dock instead, or in IDEalize open Brains > Services and choose "Import keys file".

Keep it private

The file is the same as the passwords to those accounts: usage on the keys is billed to the team. Do not forward it, put it in a chat, or commit it to a repository. If you think it has leaked, tell the person who gave it to you and they will rotate the keys and send a new file.

Your own accounts

You can add your own services alongside these at any time in Brains > Services, including a DeepSeek account of your own. Keys you add there stay on your Mac.
